# Phase 10 — v1.0 完成版

## 目的
Phase 9までの機能を壊さず、GitHub Pagesへそのまま公開できる v1.0 として仕上げる。

## v1.0で確定した主な機能
- 麻雀した日単位の記録と過去日の追加・修正・削除
- 一発 / チョンボ / 数え役満の即時カウンター
- シングル / ダブル / 複合役満
- ローカル役満の追加・編集・削除
- 役満和了回数と役満種類コレクションの分離集計
- 半荘ごとの3人の順位記録
- 大地のみ当日合計収支を記録
- 1着率 / 平均順位 / 月間・年間・通算集計
- 収支・1着率推移グラフ
- 月間MVP / 称号 / 殿堂入り / 役満演出
- 2022〜2025年の過去データ
- JSONバックアップ / 復元
- GitHub Pages / PWA / オフライン起動

## 保存について
新規記録はブラウザの localStorage に保存する。GitHub上のコード更新とは別管理だが、ブラウザデータ削除や端末変更では失われるため、JSONバックアップを使用する。
