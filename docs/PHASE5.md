# Phase 5 — 過去記録統合

## 目的
2022〜2024年のNumbersファイルをアプリ内へ取り込み、新しい日付別記録と同じ成績画面で通算できるようにする。

## 実装内容
- `src/legacy-data.js` に2022〜2024年の過去記録を同梱
- 2022年は月単位で保存
- 2023・2024年は月ごとの1〜5週目を保存
- 成績の「月間 / 年間 / 通算」に過去記録を自動加算
- 成績画面に「過去記録」を追加し、年→月→週の順で確認可能
- 役満種類が不明な過去記録は役満コレクションから除外
- 過去データは読み取り専用とし、日付を捏造しない
- 「端末の新規データを削除」を実行しても過去記録は保持

## データ上の注意
NumbersからExcelへ変換した際、一部の集計数式は `#NAME?` になっています。そのため、2023・2024年は月別の集計数式ではなく、各月の週別元データを直接読み取って年間合計を再計算しています。2022年は月別の実数値を直接使用しています。
