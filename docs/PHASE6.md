# Phase 6

2025年データと対局成績機能を追加。

## 対局成績
- 麻雀した日単位で半荘を追加
- 各半荘で拓・あんちゃん・大地の1〜3位を保存
- 大地の収支は1日につき1つだけ保存
- 過去日も自由に追加・変更・削除可能

## 集計
- 半荘数
- 1着 / 2着 / 3着回数
- 1着率（勝率）
- 平均順位
- 大地の月間 / 年間 / 通算収支

## 2025 legacy data
元Numbersファイルを週単位の役満・一発・チョンボとして取り込み。年間合計は、拓 役満9/一発25/チョンボ2、あんちゃん 役満8/一発38/チョンボ2、大地 役満14/一発22/チョンボ3。
