# Phase 1 - アプリ仕様

## 目的

Numbersで管理していた麻雀記録を、スマホから素早く入力・確認できるアプリへ移行する。

## 記録対象

初期版では以下の3種類を記録する。

- 役満
- 一発
- チョンボ

## 基本操作

1. ホーム画面を開く
2. プレイヤーを選ぶ
3. 記録種別を選ぶ
4. 「+1」で登録
5. 日時は自動保存

誤登録に備えて直近記録の取消・編集を可能にする。

## 集計

以下の単位で集計する。

- 月間
- 年間
- 通算
- プレイヤー別
- 記録種別別

## 過去データ

2022〜2024年のNumbers記録を移行する。

既存データの粒度が年度ごとに異なる場合は、無理に日付を補完せず、元データの粒度（月・週など）を保持する。
