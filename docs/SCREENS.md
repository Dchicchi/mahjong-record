# 画面構成

## 1. ホーム

- 今年の役満・一発・チョンボ合計
- プレイヤー別簡易ランキング
- 「記録する」ボタン
- 最近の記録

## 2. 記録入力

- プレイヤー選択
- 役満 +1
- 一発 +1
- チョンボ +1
- 登録後に取り消し可能

スマホで数秒以内に入力できることを最優先する。

## 3. 履歴

- 日付順一覧
- プレイヤー絞り込み
- 種別絞り込み
- 編集
- 削除

## 4. 成績

タブ切替：

- 月間
- 年間
- 通算

プレイヤーごとに以下を表示する。

- 役満
- 一発
- チョンボ

## 5. 設定

- プレイヤー管理
- 過去データ確認
- データ出力（将来）
