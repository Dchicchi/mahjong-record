# Phase 4

## 実装内容
- 一発 / チョンボ / 数え役満を日付・プレイヤーごとの `＋ / −` カウンターで入力
- 役満は1回の和了を1レコードとして保存
- 1回の和了に複数の役満を選択できる「複合役満」に対応
- 役満ごとにシングル / ダブルを保持し、複合時は合計倍率を表示
- 数え役満は役満扱いだが通常役満とは別カテゴリで集計
- 過去日をカレンダー / 日付選択から開き、いつでも追加・修正・削除可能
- ローカル役満は名称とシングル / ダブル区分を追加・編集可能
- 役満コレクションは成立した役満の種類ごとに回数を集計
- 複合役満は役満和了回数としては1回、コレクションでは成立した各役満をそれぞれ+1
- 役満演出を強化。複合時は「複合役満」表示と合計倍率を表示

## データ設計メモ
