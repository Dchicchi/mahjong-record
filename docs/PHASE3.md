# Phase 3

## 追加した機能
- 日付単位の「この日の記録」表示
- 過去・未来の日付への追加入力
- 記録済みデータの日付変更・削除
- 役満の種類選択
- ローカル役満の追加・編集・削除
- 役満達成時の演出
- 成績画面の「役満コレクション（図鑑）」
- Phase 2 の localStorage データを自動移行

## 役満
標準役満として以下を初期搭載しています。
国士無双 / 四暗刻 / 大三元 / 字一色 / 小四喜 / 大四喜 / 緑一色 / 清老頭 / 九蓮宝燈 / 四槓子 / 天和 / 地和

仲間内のローカル役満は「設定」から自由に追加できます。

## 過去データ
2022〜2024年のデータは元ファイルの粒度を維持し、2022年は月単位、2023〜2024年は週単位として今後取り込む設計です。
Phase 3では新しい日付単位データの編集体験を先に完成させています。
