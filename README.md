# 麻雀記録

大地が入力者となり、拓・あんちゃん・大地の麻雀記録を管理するスマホ向けWebアプリです。GitHub Pagesで公開し、iPhoneのホーム画面からアプリのように使うことを想定しています。

## 主な機能
- 麻雀した日単位で記録
- 過去日をいつでも追加・修正・削除
- 一発 / チョンボ / 数え役満を ＋ / − で即時カウント
- シングル役満 / ダブル役満を区別
- 1回の和了に複数役満を紐づける複合役満
- 役満和了回数は複合しても1回として集計
- 役満種類別コレクション
- ローカル役満の追加・編集・削除
- 半荘ごとに3人の順位を記録
- 大地だけ当日の金額収支を記録
- 1着率 / 平均順位 / 月間・年間・通算収支
- 収支・1着率推移グラフ
- 月間MVP / 称号 / 殿堂入り / 役満演出
- 2022〜2025年のNumbers過去記録を同梱
- JSONバックアップ / 復元
- PWA対応（ホーム画面追加・主要画面のオフライン起動）

## 採用役満ルール
シングル役満には通常役満に加え、純正九蓮宝燈、純正緑一色、十三不塔、四槓子、大車輪、小車輪、四連刻を含みます。ダブル役満は国士無双十三面待ち、四暗刻単騎、大四喜を区別します。数え役満は役満扱いですが通常役満とは別枠で記録します。

## 過去記録
- 2022年: 月単位
- 2023年: 月＋1〜5週目
- 2024年: 月＋1〜5週目
- 2025年: 月＋週単位

過去記録で役満の種類が残っていないものは、役満回数には含めますが役満コレクションには混ぜません。

## 起動
ローカル確認は静的Webサーバー経由を推奨します。GitHubへ公開するときは、このフォルダの中身をリポジトリ直下へ置いてGitHub Pagesを有効化してください。手順は `GITHUB_PAGES.md` を参照してください。

## 保存先
新規データはブラウザの `localStorage` に保存されます。2022〜2025年の過去データは `src/legacy-data.js` に同梱されています。機種変更やブラウザデータ削除前は、設定画面からJSONバックアップを書き出してください。
